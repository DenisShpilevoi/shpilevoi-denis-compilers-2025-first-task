Реализация сканера в общем виде

Возможно произвольное количество различных токинов, каждого из которых так же можно задать произвольное количество.
В данной реализации присутствует 6 различных токенов (по аналогии с языком С):
- keyword
- contant
- operator
- punctuator
- identifier
- string-literal

Программа считывает код из файла code.txt
Обрабатывает комментарии и перезаписывает код в файл code_without_comments.txt уже без них
Обрабатывает код в code_without_comments.txt следующим образом:
- Считывает слово (токен) до пробела или конца строки;
- Если начинается с символа ", то нужно искать второй символ " чтобы закрыть строчный литерал;
- Если не строчный литерал - проверка на то, является ли считаное слово keyword, operator или punctuator;
- Если не одно из предыдущего пункта - проверка на наличие букв в токене - если есть - идентификатор
- Если нет букв - число или константа.

Сканер достаточно наивный и считает что пробелы должны разделять каждую последовательную пару токенов
